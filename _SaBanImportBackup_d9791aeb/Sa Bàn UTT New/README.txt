Sa Bàn UTT New — gói thư mục Unity

Cách dùng
1. Giải nén ZIP.
2. Chép thư mục Assets/SaBanUTTNew vào thư mục Assets của project Unity đích.
3. Dùng Unity 6000.3.0f1 (hoặc phiên bản Unity 6 tương thích) và cài package Unity Splines com.unity.splines phiên bản 2.8.4.
4. Mở scene Assets/SaBanUTTNew/ProjectLopHoc/Scenes/SaBan_Display_Preview.unity để xem sa bàn, hoặc kéo prefab Assets/SaBanUTTNew/ProjectLopHoc/Prefabs/SaBan_Display_PreviewOnly.prefab vào scene cần dùng.

Gói gồm scene preview, prefab sa bàn và miniature, script runtime cùng các asset phụ thuộc được tham chiếu (model, texture, material và prefab liên quan). File .meta và GUID gốc được giữ nguyên để Unity nối lại tham chiếu.

Project nguồn dùng URP 17.3.0. Nếu project đích dùng render pipeline khác, có thể cần chuyển đổi shader/material trong Unity.
